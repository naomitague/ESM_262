Looping (or repetition)

Repeating something is a fundamental concept in programming

We usually call this looping

All programming languages have ways to do this - sometimes hidden

Lets start with the basics of how you do repetition - * the for loop - used in many languages

For loops

for statement

  • defines a loop using a counter that is incremented each time you go through the loop

  • the counter - could be any variable (we often use i) but you could use whatever variable you want

  • repeats the commands between the { and } after the for keyword and loop definition

  • these commands are repeated until the counter condition is TRUE

# simple example - use a loop to sum the numbers from 1 to 5
# a = 0+1+2+3+4+5
a=0
for (i in 1:5) {
 a = a+i
}
a
[1] 15

Break it down

  • for (i in 1:5) - mean you start with i=1

  • the commands in the loop are executed - a = a+i

  • then you go back to the top of the loop and increment i to 2

  • i = 1

  • a = 0 + 1 = 1

  • i = 2

  • a = 1 + 2 = 3

  • i = 3

  • a = 3 + 3 = 6

  • i = 4

  • a = 6 + 4 = 10

  • i = 5

  • a = 10 + 5 = 15

after the loop a = 15

Keeping track of what happens each step/interation

  • start with a data structure to hold the results -

  • initialize to 0

    • its good practice to initialize data before a loop
    • initialize means to create a data structure and set values, usually to zero but sometimes NA
# if you want to keep track of a for each iteration
# start with a data structure to hold the results - 
# there will be 5 iterations, so a vector of length 5
# initialize to 0 

av = rep(x=0, times=5)

# now we can fill in the vector with the sum at each iteration
# we can use the counter (i) to access the correct element of the vector
# note that we have to treat the first iteration differently because we don't have a previous value to add to

for (i in 1:5) {
  if (i==1) {
    av[i] = 1
  } else {
  av[i] = av[i-1]+i
  }
}
av
[1]  1  3  6 10 15
# note that R has alternatives using functions that do this looping for you
a = sum(seq(from=1, to=5))
a
[1] 15

When to use loops

  • When you want to repeat something a specific number of times
  • R has many built in functions to do this
    • BUT sometimes won’t do exactly what you want
    • other languages also use versions of the for loop

Why loop: cross-row dependencies

While sum and mean are functions created by the R community, what if you were doing something more complex to each row?

What if we needed data from a previous row for each calculation?

Example: carry-forward net income = current year’s net + last year’s carry-forward

# note: we treat the first year differently because we don't have carry forward
# initialize our column to zero, start counter (n) at 2 instead of 1
# make the first value equal to the net of first year

account$carryforwardnet = 0
account$carryforwardnet[1]=account$net[1]
# now loop - looking backward one year to get previous years carry forward
for (n in 2:10) {
  account$carryforwardnet[n] = account$net[n]+account$carryforwardnet[n-1]
}

# plot - use color to show current year's contribution as positive or negative
ggplot(account, aes(year, carryforwardnet, fill=net, group=year))+geom_col()+
  scale_fill_gradient(low="red", high="black")

Why loop: sequential comparisons

Another case where loops are necessary: comparing across elements one at a time

Lets say we are measuring speeds and we want to determine the number of times speeds are above a threshold

There are many ways to do this - but for will always work

# speed limit 
speedthresh = 120
# create some sample speeds 
speeds = runif(min=0, max=150, n=300)

nthresh = 0
for ( i  in 1:length(speeds)) {
   if(speeds[i] > speedthresh)
     nthresh = nthresh + 1
}

nthresh

Add some complexity

Lets imagine that we have data on running speeds of a creature we are trying to develop a conservation plan for

We think that

  • when the creature is running at 35 km/hr and above they are hunting.
  • when they are moving below 5 km/hr they are socializing
  • when they are moving as speeds between this they are traveling

We want to estimate how often they are in each of these categories based

Build a for loop to do this (there are other ways to get there with R but we want to practice looping)

As before, generate some test data using functions in R that allow you to generate data by sampling from distributions with known parameters

# make up sample data
speeds = runif(min=0, max=50, n=500)

# setting a named variable for the threshold makes the code easier to read and change
hunting_speed = 35
social_speed = 5
num_hunting_speeds=0
num_social_speeds = 0
for ( i  in 1:length(speeds)) {
  num_hunting_speeds = num_hunting_speeds + ifelse(speeds[i] >= hunting_speed, 1, 0)
    num_social_speeds = num_social_speeds + ifelse(speeds[i] <  social_speed, 1, 0)
}


for (i in 1:300)
